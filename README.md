# Pocket Scientific Calculator

A scientific calculator, a 2D and 3D grapher, and a class timetable.
Everything runs in the browser, on your own phone.

**<https://vannyz1013.github.io/clock2/>**

---

This repo holds the built site and nothing else. Every file in it is
generated -- editing one here will be overwritten by the next publish.

The source lives in a private repo. Changes are made there in
`app/`, then published with `node tools/publish-site.js`.
